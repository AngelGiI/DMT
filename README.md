# Data Mining Techniques Projects Overview

This repository contains projects from the **Data Mining Techniques** course, focusing on real-world applications of data mining concepts, including preprocessing, feature engineering, classification, and predictive modeling.

---

## Assignments

### **Assignment 1: Predicting Mood Using Sensor Data**
- **Objective**: Predict the mood of users based on behavioral data collected via smartphone sensors.
- **Key Topics**:
  - Data preprocessing (handling missing values and outliers)
  - Feature engineering (transforming temporal data for predictive modeling)
  - Classification (evaluating multiple algorithms for prediction)
  - Evaluation metrics (accuracy and other suitable metrics)
- **Outcome**:
  - Implemented and compared classification models.
  - Explored the impact of feature engineering on predictive performance.

### **Assignment 2: Hotel Booking Recommender (Missing Files)**
- **Objective**: Develop a recommender system to predict hotel bookings for Expedia using large-scale user interaction data.
- **Key Topics**:
  - Exploratory Data Analysis (EDA) on 5 million records
  - Feature engineering and handling missing values
  - Modeling and evaluating using recommender system techniques
- **Note**: Files for this assignment are not included in the repository.
